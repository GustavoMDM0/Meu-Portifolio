# 🌌 Meu Portfólio

Bem-vindo ao meu portfólio! 🚀  
Este é um projeto pessoal desenvolvido para apresentar minha trajetória, meus projetos e minhas habilidades como desenvolvedor front-end.

## 🔥 Sobre o Projeto

Trata-se de um portfólio pessoal com uma pegada espacial e moderna. Aqui você encontra minhas informações, meus projetos, certificados e formas de contato.

O grande diferencial desse portfólio está nos **efeitos visuais**, que vão além do básico que aprendi inicialmente. Me dediquei a pesquisar e implementar elementos que deram vida ao site, como:

- ⭐ **Animações de partículas** no fundo, usando a biblioteca `tsParticles` para criar um efeito de estrelas em movimento.
- ✨ **Glow (brilho neon)** nos botões, títulos e alguns elementos, criando uma estética futurista.
- 🪐 Ícones de tecnologias que se movem como planetas, trazendo uma vibe espacial interativa.
- 🎨 Design responsivo e adaptável, utilizando **Bootstrap** como auxílio no grid e no layout.
- 🖥️ Animações suaves feitas manualmente em CSS.
- 🎥 Interações com JavaScript puro, sem frameworks JS como React ou Vue.

## 📄 Tecnologias Utilizadas

- HTML5
- CSS3 (com efeitos avançados, sombras, glows e animações)
- JavaScript puro (para interatividade)
- [Bootstrap](https://getbootstrap.com/) (para responsividade e layout)
- [tsParticles](https://particles.js.org/) (para as partículas no fundo)

## 🎯 Funcionalidades

- 🔭 Seção inicial com nome, foto e apresentação.
- 🛰️ Seção de tecnologias com ícones que se movimentam como planetas.
- 📜 Formação acadêmica e certificados.
- 🚀 Galeria de projetos hospedados, cada um com link direto para o site e para o GitHub.
- 📥 Botão para baixar meu currículo em PDF.
- 🌌 Animações, glow neon, partículas no fundo e uma estética futurista.
